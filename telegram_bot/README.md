# بوت القرار — BOT 360

ترسل لبوتك اسم العملة (مثل `ETH`)، فيجمع التحليل من ست زوايا ثم يعطيك قرار سبوت صريح:

| الزاوية | المصدر |
|---|---|
| فني BOT 360 | يدخل بحسابك ويضغط الأدوات ويقرأ الردود |
| فني مستقل | شموع Binance: RSI وEMA 20/50/200 والاتجاه والحجم على 1h و4h و1d |
| أساسي | CoinGecko: الترتيب، القيمة السوقية مقابل FDV، السيولة، البعد عن القمة |
| السوق العام | الخوف والطمع، هيمنة BTC، اتجاه BTC |
| الأخبار | الخبير يبحث في الويب عن أخبار آخر 7 أيام |
| محللو القنوات | منشورات قنواتك عن العملة، موزونة بوصفك لأسلوب كل محلل |

ثم يقرأ **الخبير (Claude)** كل ذلك، ويقاطع المصادر، ويكتب: الزبدة، وقرار السكالب، وقرار السوينغ (دخول ووقف وأهداف وثقة)، وسطرًا لكل زاوية، وما الذي يلغي القرار. إذا لم يوجد مفتاح API يعمل محرك القواعد وحده.

## الأوامر

- `ETH`: تحليل كامل
- `/addch @channel وصف أسلوب المحلل ودقته`: إضافة قناة محلل. مثال: `/addch @xyz وايكوف، دقيق في السوينغ، يبالغ في الأهداف`
- `/delch @channel`: حذف قناة
- `/channels`: عرض القنوات

## التشغيل على جهازك

1. ثبّت Python 3.10 أو أحدث.
2. من داخل المجلد `telegram_bot`:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # ويندوز
   source .venv/bin/activate     # ماك / لينكس
   pip install -r requirements.txt
   ```
3. انسخ `.env.example` إلى `.env` واملأ القيم، ومنها `ANTHROPIC_API_KEY` للخبير. تكلفة التحليل الواحد تقريبًا 0.05 إلى 0.15 دولار، حسب طول الردود والبحث.
4. شغّل:
   ```bash
   python -m bot360.main
   ```
   أول مرة يطلب رقم هاتفك وكود الدخول الذي يصلك على تيلجرام، ثم ينشئ ملف `user_session.session`. **لا تشارك هذا الملف مع أحد**، فهو يعادل الدخول إلى حسابك.
5. افتح بوتك وأرسل: `ETH`

## ملاحظات

- كل رد خام يُحفظ في `raw_replies/` لتحسين قراءة الأدوات لاحقًا.
- الأدوات المقروءة حاليًا بدقة: SCALPING (الدعوم، الدخول، الوقف، ماركوف، GARCH) وصيغة البايفوت (R/S/H/L والارتكاز). باقي الأدوات تُقرأ بشكل عام إلى أن نضيف صيغتها.
- `python -m pytest` يشغّل الاختبارات.
- القرار مبني على مخرجات أدوات BOT 360 فقط، وليس ضمانًا.
