# بوت القرار — BOT 360

ترسل لبوتك اسم العملة (مثل `ETH`)، فيجمع التحليل من ست زوايا ثم يعطيك قرار سبوت صريح:

| الزاوية | المصدر |
|---|---|
| فني BOT 360 | يدخل بحسابك ويضغط الأدوات ويقرأ الردود |
| فني مستقل | شموع Binance: RSI وEMA 20/50/200 والاتجاه والحجم على 1h و4h و1d |
| أساسي | CoinGecko: الترتيب، القيمة السوقية مقابل FDV، السيولة، البعد عن القمة |
| السوق العام | الخوف والطمع، هيمنة BTC، اتجاه BTC |
| الأخبار | الخبير يبحث في الويب عن أخبار آخر 7 أيام |
| محللو القنوات | منشورات قنواتك عن العملة، موزونة بوصفك لأسلوب كل محلل |

ثم يقرأ **الخبراء** كل ذلك ويقارنون المصادر ببعضها. الخبراء هم أي ذكاء اصطناعي وضعت مفتاحه:

| الخبير | المفتاح | ملاحظة |
|---|---|---|
| Gemini | `GEMINI_API_KEY` | الأسهل، وفيه طبقة مجانية من aistudio.google.com |
| ChatGPT | `OPENAI_API_KEY` | مدفوع، ويبحث عن الأخبار بنفسه |
| Claude | `ANTHROPIC_API_KEY` | مدفوع، ويبحث عن الأخبار بنفسه |

- **مفتاح واحد:** خبير واحد يكتب الزبدة والقرارين وسطرًا لكل زاوية.
- **أكثر من مفتاح:** لجنة. كل خبير يحلل وحده ويصوّت، والبوت يعرض الأغلبية ومن خالفها ومتوسط الثقة، مع التحليل الكامل لأحد خبراء الأغلبية. عند التعادل يُرجَّح الخيار الأحذر.
- **بدون مفاتيح:** يعمل محرك القواعد وحده.

## الواجهة

عند التشغيل تظهر أزرار القائمة: 📊 تحليل، ⭐ المراقبة، 🔔 التنبيهات، 💼 صفقاتي، ⏰ التذكيرات والجدولة، 📜 السجل، 📢 القنوات، ⚙️ الإعدادات.

### ⚙️ الإعدادات (أزرار تشغيل وإطفاء)
- 🤖 **النماذج:** تشغيل أو إطفاء Claude وGemini وChatGPT، ويظهر بجانب كل نموذج إن كان له مفتاح.
- 🧰 **أدوات BOT 360:** اختيار الأزرار التي يضغطها البوت.
- 📡 **المصادر:** BOT 360، الفني المستقل، الأساسيات، حالة السوق، القنوات.
- 🔔 **الإشعارات:** تغيّر القرار، منشورات القنوات، الأخبار، حركة BTC العنيفة، الملخص اليومي.
- ⏱️ **التوقيت:** المنطقة الزمنية، وقت الملخص، فترة فحص تغيّر القرار، حد الحركة العنيفة.

### ما يعمل تلقائيًا في الخلفية (كل دقيقة)
| الميزة | كيف |
|---|---|
| 🔔 تنبيه سعر | `/alert ETH < 1600` |
| 💼 متابعة صفقة | زر «📌 تابع الصفقة» تحت التحليل، أو `/trade ETH 1620 1580 1700 1750`: تنبيه عند الدخول، وكل هدف، والوقف |
| 🔄 تغيّر القرار | عملات `/watch` تُحلَّل كل X ساعات، ولا تصلك رسالة إلا إذا تغيّر القرار |
| 🗓️ تحليل مجدول | `/every 4h ETH` أو `/daily 09:00 BTC ETH` |
| ⏰ تذكير | `/remind 3h نص` أو `/remind 21:00 نص` أو `/remind 2026-12-01 09:00 نص` |
| ☀️ ملخص يومي | الخوف والطمع، أسعار المراقبة، الصفقات، تذكيرات اليوم |
| 📰 أخبار | CoinDesk وCointelegraph وDecrypt: 🚨 اختراقات، 🌍 سياسة واقتصاد، 🟢 فرص، وأي خبر عن عملاتك |
| 📢 القنوات | منشور جديد من قنواتك عن عملة في المراقبة، أو تحذير أمني أو سياسي |
| ⚡ حركة عنيفة | BTC يتحرك أكثر من 3% خلال ساعة |
| 📜 السجل | كل قرار يُحفظ، و«📜 السجل» يقارنه بسعر اليوم ويحسب نسبة الدقة |

اكتب `/help` داخل البوت لرؤية كل الأوامر.

## التشغيل على جهازك

1. ثبّت Python 3.10 أو أحدث.
2. من داخل المجلد `telegram_bot`:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # ويندوز
   source .venv/bin/activate     # ماك / لينكس
   pip install -r requirements.txt
   ```
3. انسخ `.env.example` إلى `.env` واملأ القيم، ومنها مفتاح خبير واحد على الأقل. للبداية المجانية يكفي `GEMINI_API_KEY`.
4. شغّل:
   ```bash
   python -m bot360.main
   ```
   أول مرة يطلب رقم هاتفك وكود الدخول الذي يصلك على تيلجرام، ثم ينشئ ملف `user_session.session`. **لا تشارك هذا الملف مع أحد**، فهو يعادل الدخول إلى حسابك.
5. افتح بوتك وأرسل: `ETH`

## ملاحظات

- كل رد خام يُحفظ في `raw_replies/` لتحسين قراءة الأدوات لاحقًا.
- الأدوات المقروءة حاليًا بدقة: SCALPING (الدعوم، الدخول، الوقف، ماركوف، GARCH) وصيغة البايفوت (R/S/H/L والارتكاز). باقي الأدوات تُقرأ بشكل عام إلى أن نضيف صيغتها.
- `python -m pytest` يشغّل الاختبارات.
- القرار مبني على مخرجات أدوات BOT 360 فقط، وليس ضمانًا.
